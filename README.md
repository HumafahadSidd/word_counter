# 📝 Word Tally – CLI Word Counter

A simple and interactive **Word Counter CLI Application** built with TypeScript and Node.js using Inquirer and Chalk. This application allows users to enter a sentence and instantly count the total number of words through a command-line interface.

## 🚀 Features

- Count words in a sentence.
- Interactive user input using Inquirer.
- Display entered words in an array.
- Calculate and display the total word count.
- Colorful terminal output using Chalk.
- Simple and beginner-friendly interface.

## 🛠️ Technologies Used

- **TypeScript** – Programming language
- **Node.js** – JavaScript runtime
- **Inquirer** – Interactive command-line prompts
- **Chalk** – Colorful terminal output

## 📦 Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project directory:

```bash
cd word-tally
```

Install dependencies:

```bash
npm install
```

## ▶️ How to Run

Run the application using:

```bash
npx tsx main.ts
```

## 📖 How to Use

1. Run the application in your terminal.
2. Enter a sentence when prompted.
3. The application splits the sentence into individual words.
4. View the words displayed in an array.
5. Get the total word count instantly.
